# 任务：前缀键（老板键）可配置化

## 背景与目标

当前快捷键前缀固定为 ctrl+shift（散落在各平台绑定表中硬编码）。目标：抽出统一的前缀键配置项，用户改一处配置即可让所有带前缀的快捷键整体切换（一键更改），无需逐条改绑定。

## 需求细节

- 新增配置项，如 `prefix = "ctrl+shift"`（或单一 modifier 组合描述）
- 所有依赖该前缀的内置绑定自动使用配置值
- 默认值保持 ctrl+shift，不破坏现有习惯
- 用户自定义 key_bindings（`config_key_bindings`）同样可用该前缀写法

## 设计调研（20261118 架构调研结论）

- ctrl+shift 绑定定义：`frontends/tapterm/src/bindings/mod.rs`
  - 分平台 `platform_key_bindings`（Linux 版 L1266 起，如 L1273-1288）
  - `Action` 枚举 L328；`BindingMode` L157；配置覆盖 `config_key_bindings` L1002
- 配置结构：`tap-backend/src/config/bindings.rs`（`KeyBinding { key, with, action, esc, mode }`）
- 配置加载：`tap-backend/src/config/mod.rs` `Config` L157、`try_load` L483 / `load_from_path` L366
- 新增配置项路径：加字段 + serde rename + `tap-backend/src/config/defaults.rs` 默认函数
- 改造思路：绑定构造时用配置的前缀替代硬编码 `CONTROL | SHIFT`；注意 `with` 是 modifier 位掩码，前缀配置需解析为位掩码组合

## 关键子任务

1. 设计统一 prefix 配置项（一处配置，全部绑定生效）
2. 配置加载与默认值（现默认 ctrl+shift）
3. 绑定生成改造，去除散落的硬编码前缀

## 实施记录

（20261118 实施完成）

### 配置层（tap-backend）

- `config/bindings.rs`：`Bindings` 结构体新增 `prefix: String` 字段（serde 默认函数），手动实现 `Default`（原为 derive）
- `config/defaults.rs`：新增 `default_binding_prefix()`，默认值 `"ctrl+shift"`
- 配置写法：

```toml
[bindings]
prefix = "ctrl+shift"   # 可写 "alt"、"super | ctrl" 等，+ 或 | 分隔
keys = [ ... ]          # 原有自定义绑定不变
```

- 词表（大小写不敏感）：`control`/`ctrl`、`shift`、`alt`/`option`、`super`/`cmd`/`command`、`none`

### 绑定生成（frontends/tapterm/src/bindings/mod.rs）

- 新增 `parse_modifiers(&str) -> ModifiersState`：把前缀描述解析为 modifier 位掩码（`+`/`|` 分隔），未知词 warn 并忽略
- `default_key_bindings`：解析 `config.bindings.prefix` 一次，传入 `platform_key_bindings` 与 `config_key_bindings`
- 三个平台 `platform_key_bindings`（macOS / Linux / Windows）均增加 `prefix: ModifiersState` 参数，所有硬编码 `CONTROL | SHIFT` 替换为 `prefix`（divider 移动键为 `prefix | ALT`）；macOS 仅一处（Tab 上一个标签），SUPER 系绑定不动
- 非「前缀」绑定不受影响：如字号 Ctrl+0/=//-、Ctrl+Tab 下一个标签、搜索模式内 Ctrl 系、Insert+Shift 粘贴等保持原样
- `convert()` / `config_key_bindings()` 透传 prefix；`with` 字段支持 `prefix` token（如 `with = 'prefix'`、`with = 'prefix | alt'`），用户自定义绑定同样跟随前缀配置；`with` 分隔符同时支持 `|` 与 `+`
- 配置热重载已覆盖：`application.rs` 比较 `config.bindings`（含 prefix 变化）触发 quake 快捷键重建，screen 端 `default_key_bindings` 重建绑定

### 修复（20261119-1128，[bindings] 只写 prefix 报 missing field keys）

`Bindings.keys` 缺 serde 默认值：配置文件里 `[bindings]` 段只写 `prefix = "..."`（最常见用法）时启动报 TOML parse error "missing field keys" 并回落默认配置（prefix 随之失效）。补 `#[serde(default = "KeyBindings::default")]` + 测试（prefix-only 段与空段均按默认解析）。tap-backend bindings 10 测试通过。
