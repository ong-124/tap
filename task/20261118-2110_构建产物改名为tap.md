# 任务：构建产物改名为 tap

## 背景与目标

fork 已定名 tap（配置目录、默认值均已切换），但构建产物仍叫 rio：二进制 `target/{debug,release}/rio`（`frontends/rioterm/Cargo.toml` 的 `[[bin]] name = "rio"`）、窗口 WM_CLASS/app_id 为 "Rio"、desktop 文件与 Makefile 引用 `rio`。目标：最终产物统一为 tap。

## 设计

- `frontends/rioterm/Cargo.toml`：`[[bin]] name = "rio"` → `"tap"`；deb 打包资源路径 `target/release/rio` → `tap`
- `frontends/rioterm/src/router/window.rs`：`APPLICATION_ID = "Rio"` → `"Tap"`（Linux WM_CLASS / Wayland app_id；`--app-id` CLI 覆盖机制不变）
- `misc/rio.desktop` → `misc/tap.desktop`：TryExec/Exec/Icon=tap，Name=Tap，StartupWMClass=Tap
- `Makefile`：release-x11/wayland 目标中 `target/release/rio` → `tap`
- 自引用安全性：进程自重启走 `std::env::current_exe()`（teletypewriter/src/unix/child.rs L517），无硬编码二进制名
- 范围外未动：pkgRio.nix / flake.nix（上游 nix 打包）、TERM_PROGRAM、~/.cache/rio（shell integration 缓存）、vulkan 管线缓存路径、通知 icon、Windows wxs / macOS plist 打包模板

## 关键子任务

1. bin 名称 + APPLICATION_ID + desktop 文件 + Makefile 修改
2. 编译验证
3. 用户实测（target/debug/tap 运行、任务栏/WM_CLASS 显示）
