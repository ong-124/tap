# 任务：输入栏自建历史库 + 虚化预选 + Tab 补全

## 背景与目标

输入栏（20261118-1941）三个痛点：① ↑/↓ 只回显本会话内存历史；② Tab 直通 PTY（提示符下触发 shell 对空行补全，屏幕乱码）；③ 无 zsh-autosuggestions 式虚化建议。本任务接管旧任务「已知限制」中的 Tab 直通与内存态历史两条。

## 设计哲学（用户拍板）

**tap 记录的是「你对我的输入」，不负责终端历史。** 提示符下所有按键都先进输入栏，tap 天然全量可见提交过的命令 → 自建持久历史库即可达成 ↑/↓ 回显与虚化预选。**明确不做**：HISTFILE 解析、shell 集成、镜像方案（讨论后否决：zle 钩子镜像工程风险在启动链，Rust 重写永远追不上 zle 生态，而输入栏架构使 tap 自身记录 ≈ 完整历史）。

用户确认的决策：排序**新近优先**；虚化建议 = autosuggestions 语义（前缀匹配、光标尾部、`→`/`End` 接受、编辑消失、preedit 压制）；Tab 补全**仅文件系统**（不掺历史词），多候选 = 候选行 + Tab 循环，唯一命中目录补 `/`、其余补空格；Shift+Tab（BackTab）保持直通；自定义裸 Tab 绑定优先于输入栏（逃生口）。
