# 任务：输入栏动态补全（Cobra `__complete` 协议）+ SSH 主机/远程补全

## 背景与目标

现有 Tab 补全（20261119-1527）是静态的：首词 PATH 命令、其余词文件系统路径。`kubectl get pod<TAB>` 这类需要**实时上下文数据**（K8s API 里的 pod 名）的补全完全无解。用户痛点两组：本地 Cobra 系 CLI（kubectl/helm/gh…）资源名补全；ssh 场景（一次性 `ssh host cmd` 与修复轮次八后输入栏保持可用的交互式 ssh 会话内）。

术语：**可编程/动态补全**（bash programmable completion、zsh compsys 为 shell 层方案，外部进程调不到）。tap 的切入点是 **Cobra 动态补全协议**：Cobra 系 CLI 全部自带隐藏命令 `__complete`/`__completeNoDesc`，直接 spawn 二进制即可获取候选，无需任何 shell 集成——与「tap 不做 shell 集成」的设计哲学兼容。

## 协议要点（拍板依据）

```bash
kubectl __completeNoDesc get pod my-   # 前面的 argv 原样传，末参 = 待补词（可空串）
my-app-7f9c8d-x2v9s                    # 每行一个候选（desc 版为 name\tdesc）
:4                                     # 末行指令位掩码
```

指令位：`2` 单候选后不加空格、`4` 候选权威（**不得**回退文件补全）、`16` 候选为目录、`32` 保持顺序。同协议覆盖 kubectl/helm/gh/argocd/flux/kind/istioctl/docker。

## 设计（用户确认「全做」范围）

| 层 | 决策 |
|---|---|
| 路由 | 纯函数 `route()`：按缓冲 argv 分发到 静态命令 / 静态路径 / ssh 主机表 / 动态请求；`command-aliases` 配置可把 `k` 映射到 `kubectl` 等真名 |
| ssh 一次性 | `ssh [flags] host cmd…` 解析出 host 与 remote argv；待补词在 host 槽位 → 静态主机表（`~/.ssh/config` 非通配 Host + known_hosts 非 hashed，`user@` 前缀处理）；host 后 → 远程执行 `ssh -o BatchMode=yes -o ConnectTimeout=3 host -- <sh_quote 拼接>` |
| ssh 会话内 | 输入栏在 ssh 会话中保持可用（轮次八），tap 经 `tcgetpgrp` + `/proc/<pgid>/cmdline` 探测前台 ssh 进程拿到 host（autossh 亦然），**侧信道**另开连接查询补全——绝不向现存会话注入文本；host 已知后远程行首词 → 远程 `bash -c compgen -A command`，其余词按 Cobra 走远程 `__completeNoDesc` |
| 异步 | 动态查询打 API 可达秒级：后台线程 + mpsc，看门狗 50ms 轮询，超时（本地 5s / 远程 12s）kill；Tab 先静默消费，结果经 `poll_dynamic()`（render 每帧 + 击键入口）到达且 buffer 指纹未变才填充候选行，旧请求被新请求顶替后自然作废 |
| 缓存 | bar 内 `HashMap<key,(Instant,候选,flags)>`，TTL 10s（Tab 循环不重查、资源列表保新鲜），超 128 全清 |
| 语义 | 动态上下文**不做**静态回退（`:4` 下文件名候选是噪音）；`:2` → Candidate 加 no-space；`:32` 保序不排序；候选 cap 100；远程参数经 sh_quote 转义 |

## 实施（20261119-1824 完成）

| 层 | 文件 | 内容 |
|---|---|---|
| 路由 | `frontends/rioterm/src/completion.rs` | `tokenize` shell-lite 分词（引号/反斜杠、原样 raw span 供替换）、`ssh_route`（值选项分离/内联 `-p2222`/`--`，无目的地时 `dest_slot=argv.len()` 使 `ssh <Tab>` 仍出主机表）、`ssh_flag_takes_value`、`resolve_tool`（别名→COBRA_TOOLS 8 工具白名单）、`route()` 纯函数（Command/Path/SshHosts/Dynamic/None，会话 host 优先级最高） |
| 协议 | 同上 | `DynamicRequest{Cobra/RemoteCommands}` + `key()`（\u{1} 连接，指纹比对）、`spawn_dynamic` 后台线程（stdout 读到 EOF，看门狗 50ms 轮询、本地 5s/远程 12s kill、`Arc<Mutex<Child>>`）、`sh_quote`、`ssh_command`（BatchMode+ConnectTimeout=3 侧信道）、`parse_complete_output`（**过滤 `_activeHelp_` 行**——helm 实测发现 Cobra 会向 stdout 注入提示，官方脚本同样过滤；`:2/:16/:32` 指令落实，cap 100）、`ssh_host_candidates`（config 非通配 Host + known_hosts 非 hashed，`user@` 头保留，排除 Match 行误判） |
| 探测 | `teletypewriter/src/unix/mod.rs` | `foreground_process_cmdline`（复用 tcgetpgrp 逻辑抽 `foreground_process_pid`；Linux/FreeBSD 读 /proc cmdline，macOS 无 procfs 用 `ps -p -o command=`）——pane 前台是 ssh/autossh 即取其目的地 |
| 引擎 | `frontends/rioterm/src/renderer/input_bar.rs` | 新字段 `dynamic/aliases/session_ssh_host/pending/dynamic_cache`；`set_options` 扩 4 参（开关或别名变更时清 pending）；锁定清 pending；`tab_complete` 重写为路由分发（cycle 快路径不变），`token_context` 替代 word_before_cursor（原函数删除）；`start_dynamic`（缓存 TTL 10s 命中即用、同 key 等待、否则 spawn）；`poll_dynamic`（render 每帧 + screen 击键 + Tab 前各 poll 一次；try_recv、密文/preedit 压制、`current_dynamic_request` 重算 key 不匹配即丢）；`apply_candidates_at` 抽出共享单选/菜单逻辑；`dynamic=false` 回退旧静态行为；DYNAMIC_CACHE_TTL 10s、超 128 全清 |
| 接线 | `screen/mod.rs` | `input_bar_tab_complete` 检测前台 cmdline → ssh_route.dest 填 `Sources.session_ssh_host`；Tab 前 poll；`process_input_bar_key` 入口 poll（击键送达）；两处 `set_options` 调用（Renderer::new + update_config）补 dynamic/aliases |
| 配置 | `rio-backend/src/config/input_bar.rs` | `dynamic-completion`（默认开）+ `command-aliases`（HashMap，默认空；`[input_bar.command-aliases] k = "kubectl"`）；InputBarConfig 去掉 Copy（HashMap 所迫） |

## 实施偏差与修复记录

- 首版 `spawn_dynamic` 写残（占位垃圾/RemoteCommands 丢 word/漏 parser）整体重写：读 stdout 至 EOF 即天然受看门狗约束，无需 try_wait 轮询循环
- `ssh_route` 初版「仅 flags 无目的地」返回 None 导致 `ssh <Tab>` 无候选；改为返回 `dest_slot=argv.len()`；`remote_start` 恒为 `dest_slot+1`（否则 `ssh web1 <Tab>` 无路由）
- InputBarConfig 原带 Copy，HashMap 字段编译失败 → 去 Copy
- Candidate 补 `#[derive(Debug, Clone)]`（缓存与测试需要）
- helm 冒烟实测：stdout = 候选行 + `:4`，但混有 `_activeHelp_` 提示行 → parser 增过滤 + 回归测试
- 测试期望两处手误（tokenizer 起始索引 12/21 非 11/20；ssh -p 2222 的 dest_slot 是 3 非 4）按实际语义修正
