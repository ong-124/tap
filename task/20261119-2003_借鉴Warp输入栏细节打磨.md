# 任务：借鉴 Warp 输入栏细节打磨

## 背景与目标

拉取 Warp 源码（`docs/warp`）调研后，从其补全引擎 / 历史持久化 / 建议 UI 三块实现中提炼可借鉴点（[调研结论] 见下）。本任务只做**行为与逻辑层**的细节打磨，不做 UI 视觉改动（用户拍板：UI 不抄）。前置任务：20261119-1527（历史库/虚化预选/Tab 补全）、20261119-1801（动态补全，已引入 `sh_quote` 与路由纯函数）。

架构结论存档（20261119 讨论定调）：Warp 的 block 流 + shell 集成路线不搬——其 shell 集分只买到锚点与元数据，行编辑器仍是自建（warp_completer/editor/input.rs 三大件），且放弃固定位置输入；tap 固定栏 + 终端层接管路线维持，借的只是与架构无关的手艺细节。OSC 133 只读上报作为未来候选，另行决策（注意修复轮次八已移除 zone 机制，重启需重论证 SSH 场景）。

平台边界（20261119 用户拍板）：**仅 Linux**，macOS/Windows 不做适配。新代码不再写 `#[cfg(target_os = "macos"/"windows")]` 分支（如前台进程探测的 macOS ps 路径、teletypewriter 门控）；存量跨平台代码不主动清理（条件编译留着无成本，删代码是独立任务、风险大于收益）。

## 调研结论（采纳项与出处）

Warp 源码路径以 `docs/warp/` 为根。

### P1 补全正确性（completion.rs / input_bar.rs）

1. **文件候选 shell 转义**（修真实缺陷）：现状补全含空格/引号/`$` 等文件名会产生坏命令。Warp 替换串与显示串分离——替换串转义、显示串保持原名（`crates/warp_completer/src/completer/engine/path.rs:275-336`）。落点：路径分支复用/扩展已有 `sh_quote`（`completion.rs:616`，1801 引入），显示串不动；与 Cobra 动态候选统一策略。
2. **多候选循环目录统一补 `/`**：现状唯一命中目录才补 `/`，循环选中目录无后缀无法续深子目录。Warp 目录候选一律带分隔符（`path.rs:316`）。落点：候选生成时目录项追加 `/`；注意 LCP 与循环逻辑对带 `/` 候选的字符级行为（修复轮次一的 index 语义不变）。
3. **插入前防缩短校验**：Warp Tab 应用候选前校验 `starts_with(当前输入)` 防输入被缩短（`app/src/terminal/input.rs:13736-13741`）。落点：`tab_complete`（`input_bar.rs:453`）应用前断言候选是当前词的超集，不满足则丢弃（防动态补全迟到/指纹失效）。
4. **symlink 跟随判目录**：Warp 跟随目标判目录类型（`path.rs:62-70`）。落点：目录判定改 `metadata()`（跟随）而非 `symlink_metadata()`。

### P2 历史库（input_history.rs）

5. **load 全量去重保最新**：现状相邻去重（`input_history.rs:73`），`a b a` 留三条。Warp 存储只追加、去重放展示层且保最后一次出现（`app/src/terminal/history.rs:441-462`）。落点：`load` 尾部载入后 HashSet 全量去重保最后出现，顺序仍旧→新；存储格式与追加制不变。
6. **前导空格不记录**：Warp ignorespace 语义（空命令、前导空格跳过，`crates/warp_terminal/src/shell/mod.rs:182-210`）。落点：内存 `take_submitted_line` 与持久库 submit 双处跳过 `starts_with(' ')` 及全空白行。

### P3 建议逻辑（input_bar.rs / screen/mod.rs）

7. **ghost 同 cwd 优先**：Warp 同 cwd 前缀命中优先、其余目录殿后（`app/src/terminal/model/next_command_model.rs:839-864`）。落点：`refresh_suggestion`（`input_bar.rs:407`）改两桶扫描——先扫与焦点 pane cwd 相同的条目再退全局；需 `set_history` 侧提供 cwd 元数据（`load` 现只回 line，加返回 Entry 的变体或并行映射，↑/↓ 浏览行为不变）。
8. **strip_prefix 渐进裁剪**：Warp 编辑时若新输入仍是原建议前缀，直接裁掉 ghost 尾巴不重查（`app/src/editor/view/mod.rs:7725-7774`）。落点：变异路径先试对现 suggestion `strip_prefix(新 buffer)`，成立即续用，失败走现有逆序扫描；条件（光标尾部/无 preedit/非浏览态）不变。

### P4 交互（可选，低优先）

9. **Ctrl+→ 逐词接受 ghost**：Warp word 边界作用于 ghost 剩余文本、插入一段、剩余续作 ghost（`mod.rs:6006-6076`）。落点：`screen/mod.rs` 路由 Ctrl+Right → input_bar 新方法 `accept_suggestion_word`；注意与既有绑定查重。
10. **Tab 决策纯函数化**：Warp 四态枚举 NoAction/InsertSingle/InsertCommonPrefixAndOpen/Open（`suggest/mod.rs:291-306`）——若 P1 改动中自然触碰则顺手重构为纯函数，不强求。

### 明确排除（记录原因，防止回头重议）

- **OSC 133 只读上报**：已决策采纳，另立任务 [20261119-2024_OSC133信号接入输入栏](20261119-2024_OSC133信号接入输入栏.md)（核查发现 upstream rio 的注入/解析/事件全量存在，收敛为消费侧接线）；本任务 P3-7 的 cwd 取值将由该任务接线二提供

## 实施记录（20261119）

改动面：`completion.rs`、`input_history.rs`、`renderer/input_bar.rs`、`screen/mod.rs`（行为与逻辑层，无 UI 视觉改动；无新增 cfg 平台分支）。

### P1 补全正确性

1. **文件候选 shell 转义**：新增 `sh_escape`（completion.rs）——反斜杠逐字符转义，safe 集 = 字母数字 + `_ @ % + = : , . / -` + 非 ASCII（shell 元字符全 ASCII）；头部 `~/` 特判保持 tilde 展开（对齐 Warp `shell_escape`，warp_util/path.rs:294）；与 `sh_quote`（ssh 行整词单引号）分工并存。应用三处：`path_candidates`（head+completed 整体转义，head 来自 tokenizer 还原的无引号词须一并重转义）、`parse_complete_output`（Cobra 候选）、`command_candidates`。显示串（`Candidate.display`）一律保留原名。循环态配套：`CompletionState.current` 与 LCP 比较改存 `unescape_word`（tokenize 首 token）还原的无引号词，转义插入后 Tab 循环/高亮语义不变（修复轮次一的 index 语义保持）。
2. **多候选循环目录统一补 `/`**：经核对 `path_candidates` 生成时已对所有目录候选烘焙 `/`（唯一命中与循环同源），真正缺口在 symlink 目录（`DirEntry::file_type` 不跟随 → 无 `/` 无法续深）；随第 4 项修复补齐。带 `/` 候选的 LCP/循环字符级行为不变（既有测试覆盖）。
3. **插入前防缩短校验**：`apply_candidates_at` 双处 guard——单候选 `unescape_word(insert).starts_with(word)` 否则丢弃；多候选 LCP 同判，不满足时**整组丢弃**（仅不插 LCP 仍开菜单会让下一次 Tab 应用不延伸候选，同样缩短输入，故比 Warp 更严）。循环分支不加 guard（foobar2 → foobar 是合法缩短）。
4. **symlink 跟随判目录**：`path_candidates` 判目录改 `std::fs::metadata(entry.path())`（跟随目标），断链 symlink 兜底按文件处理（无 `/`）。

### P2 历史库

5. **load 全量去重保最新**：`load` 重构为 `load_entries(path, cap) -> Vec<Entry>`（带 ts/cwd），尾部逆序 HashSet 去重保最后出现再反转，顺序仍旧→新；cap 截断与 rewrite 语义不变，存储仍只追加。`load` 删除（无存量调用方），screen 启动改喂 `set_history_entries`。
6. **前导空格不记录**：共享谓词 `records_history_line`（非空 && 不以空格开头 && 非全空白）双处使用——`take_submitted_line` 内存 push 前跳过；screen 落盘 gate（`last_history_is` 本就会因内存未收而 false，谓词显式兜底）。行仍照常发送 PTY。

### P3 建议逻辑

7. **ghost 同 cwd 优先**：InputBar 新增 `history_cwds`（与 history 平行的逐条 cwd）与 `focus_cwd`；供数三点——`set_history_entries`（启动载入）、`set_last_history_cwd`（提交后 screen 回填本次运行 cwd）、`set_focus_cwd`（提交与 Tab 时快照焦点 pane cwd，均为已有 /proc 探测点，无新增探测开销）。`refresh_suggestion` 扫描改两桶：逆序先命中同 cwd（双非空且相等）者胜，否则全局最近命中；无 cwd 元数据条目（旧 store 三列兼容、会话内未回填）不参与优先。↑/↓ 浏览行为不变。
8. **strip_prefix 渐进裁剪**：新增 `suggestion_line`（ghost 来源整行）。`refresh_suggestion` 先试裁剪——buffer 仍为该行严格前缀时直接取尾续用（打字缩尾、退格长尾回来），偏移才走重扫（重扫会跳到别的条目，裁剪期间 ghost 不跳——用两候选测试钉死该差异）；`set_focus_cwd` 变更清 `suggestion_line` 绕过裁剪直接按新目录重排序。资格条件（光标尾部/无 preedit/非浏览态/非密文）不变，所有 suggestion 置 None 的位点同步清 `suggestion_line`。

### P4 交互

9. **Ctrl+→ 逐词接受**：`accept_suggestion_word`——跳过 ghost 头部空白后取首词（含前导空白一并入 buffer），剩余续作 ghost 且不动 `suggestion_line`（仍是其前缀）；ghost 耗尽清两态。路由：`process_input_bar_key` Ctrl 分支 NamedKey::ArrowRight，有 ghost 消费返回 true，无 ghost 返回 false 透传终端 word-right（`\x1b[1;5C`）；查重确认默认绑定无裸 Ctrl+→（仅 Ctrl+Super=MoveDividerRight、前缀键体系不冲突）。
10. **Tab 决策纯函数化**：未做——P1 改动未自然触碰四态结构，按任务约定不强求。
