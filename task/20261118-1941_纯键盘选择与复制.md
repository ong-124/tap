# 任务：纯键盘选择与复制（终端面板 vim 可视模式）

## 背景与目标

不借助鼠标、也不进入 vim 编辑器，直接在当前终端面板上用键盘完成文本选择与复制：类似 vim 的可视模式操作（v 开始选择、移动扩展选区、y 复制），选中内容可进剪贴板/缓冲区，配合鼠标中键（或绑定键）输出。

## 需求细节

- 键盘快捷（可挂在前缀键下）直接进入选择模式
- vim 风格移动：h/j/k/l、w/b/e、0/$、g/gg、Ctrl+d/u 等
- v 进入可视选择（字符级），V 行级选择（可选）
- y 复制选中内容到剪贴板；也可选中即入缓冲区
- 选中后中键（已有 PasteSelection 语义）或绑定键输出
- Esc 退出选择模式，回到普通输入

## 设计调研（20261118 架构调研结论）

项目已有 vi mode 基础，本任务很大程度是"补齐/改造现有 vi mode 的可视选择体验"：

- vi 模式核心：`rio-vt/src/crosswords/vi_mode.rs`、`rio-vt/src/crosswords/mod.rs`（`toggle_vi_mode` L1216、`vi_motion` L1255、`vi_mode_recompute_selection` L1241）
- 绑定入口：`frontends/rioterm/src/bindings/mod.rs` L1288 附近 `ToggleViMode`
- 选区数据结构：`rio-vt/src/selection.rs`（`Selection` L126、`SelectionRange` L36）
- 鼠标选择流程（可复用其选区更新逻辑）：`frontends/rioterm/src/application.rs` L1527 → `frontends/rioterm/src/screen/mod.rs::start_selection` L1951、`update_selection` L2015
- 复制：`frontends/rioterm/src/screen/mod.rs::copy_selection` L1914；剪贴板封装 `rio-vt/src/clipboard.rs`
- 中键粘贴：`frontends/rioterm/src/bindings/mod.rs` L637 `PasteSelection`、`application.rs` L1530、粘贴 `screen/mod.rs::paste` L3671

## 关键子任务

1. 调研现有 vi_mode 与需求差距（进入方式、按键布局、可视选择语义）
2. 直接在终端面板进入选择模式（不依赖鼠标）
3. vim 风格移动/选择/复制（y 复制、v 可视选择）
4. 选中内容进剪贴/缓冲区，配合中键输出

## 实施记录

（20261118-2148 实施完成，构建/测试/clippy/fmt 通过，待用户手测）

调研结论：现有 vi 模式已具备绝大部分能力（Alt+Shift+Space 进出、全套 motions、v/V/Ctrl+v/Alt+v 四种选区、移动自动扩展选区、y 复制、中键 PasteSelection），本任务实为补齐差距。与用户确认的设计决策：Esc 两段式（有选区清选区/无选区退 vi）；不加新入口键（沿用 Alt+Shift+Space → v 两步）；选区实时写 PRIMARY + y 双写。

代码改动：

1. [rio-vt/src/crosswords/mod.rs](../rio-vt/src/crosswords/mod.rs)：`vi_mode_recompute_selection` 改 pub（供前端 Scroll 路径复用）
2. [frontends/rioterm/src/bindings/mod.rs](../frontends/rioterm/src/bindings/mod.rs)：
   - `ViAction` 新增 `ClearSelectionOrExit`；`From<String>` 表加 `"clearselectionorexitvi"`（可配置绑定）
   - Esc（VI 模式）从 `Action::ClearSelection` 改为 `ViAction::ClearSelectionOrExit`，并补 `~BindingMode::SEARCH`（绑定循环无 break 全量触发，防搜索态误退 vi）
   - 新增 Shift+[ / Shift+] → ParagraphUp/Down 段落移动（ViMotion 实现已有未绑键；Shift+[ 归一化为 `[`，循 `"4"+SHIFT`→$ 惯例）
3. [frontends/rioterm/src/screen/mod.rs](../frontends/rioterm/src/screen/mod.rs)：
   - 新增 `sync_vi_selection_clipboard` helper：VI 模式且选区非空时把选区写入 PRIMARY（X11 Selection）
   - `Act::Copy`（y / Copy 键）：写 CLIPBOARD 后镜像写 PRIMARY（非 VI 常规复制不受影响）
   - `Act::ViMotion`、`toggle_selection` 末尾、四个 Scroll arm（PageUp/Down、HalfPage*）、ScrollToTop/Bottom 统一调 helper → 选中即可中键输出
   - 四个 Scroll arm 补 `vi_mode_recompute_selection()` + selection_range 同步 + Full damage（修复 Ctrl+d/u 带选区不扩展的 inconsistency）；ScrollToTop/Bottom 补 selection_range 同步（修复 g/G 高亮陈旧）
   - 新增 `Act::Vi(ViAction::ClearSelectionOrExit)` arm：有非空选区 → 清选区留在 vi；VI 无选区 → `toggle_vi_mode` 退出；非 VI → 仅清选区
   - `toggle_selection` 删除换类型 arm 内旧的一次 PRIMARY 写（时机早于 include_all、内容偏旧），末尾统一写
4. [extra/man/rio-bindings.5.scd](../extra/man/rio-bindings.5.scd)：Escape 描述改两段式；补 Shift+[ / Shift+]；AVAILABLE ACTIONS 补 `ClearSelectionOrExitVi`
