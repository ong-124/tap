# 任务：默认配置固化（字体/字号/窗口/透明度）

## 背景与目标

背景图已设为默认（见 20261118-1941 任务）。用户现有 `~/.config/tap/config.toml` 中还配置了字体、字号、窗口模式与透明度；目标：新安装、无配置文件时开箱即得与当前一致的观感。

## 参考的用户现配置

```toml
[fonts]
size = 18
family = "Fira Code SemiBold"
use-drawable-chars = true

[window]
mode = "Maximized"
opacity = 0.8
```

（style/features/symbol-map 等项与代码默认等价，无需处理；背景图默认已在前一任务完成）

## 设计

- 字号默认：`sugarloaf/src/font/fonts.rs::default_font_size()` 14 → 18
- 字体默认：`SugarloafFonts.family`（Option<String>，会覆盖全部 slot 的 family，见 font/mod.rs L926-931）serde/default 改为 `Some("Fira Code SemiBold")`；不动 `DEFAULT_FONT_FAMILY`（"cascadiacode" 是内置兜底字体的标识，改它会绕过系统字体搜索直接加载内置字体）
- 窗口模式默认：`WindowMode` 的 `#[default]` Windowed → Maximized
- 窗口透明度默认：`tap-backend/src/config/defaults.rs::default_opacity()` 1.0 → 0.8
- 字体缺失时的行为：系统搜索失败 → 弹 warning + 回退内置 Cascadia Code（与显式配置同路径）

## 关键子任务

1. 字号/字体/窗口模式/透明度默认值修改
2. 编译验证（含存量默认值相关测试核对）
3. 用户实测：移走 config.toml 后冷启动观感一致

## 实施记录

- `sugarloaf/src/font/fonts.rs`：
  - `default_font_size()` 14 → 18
  - 新增 `default_family_override()` 返回 `Some("Fira Code SemiBold")`，作为 `SugarloafFonts.family` 的 serde default 与 `Default` 实现值（覆盖全部 slot 的 family，等效用户配置 `family = "Fira Code SemiBold"`）
  - 未动 `DEFAULT_FONT_FAMILY`（"cascadiacode"）：它是内置兜底字体标识，匹配它会跳过系统字体搜索直接加载内置字体
  - 字体缺失行为：系统搜索失败 → warning + 内置 Cascadia Code 兜底（与显式配置同路径）；本机已确认安装 `Fira Code SemiBold`（fc-list 可见）
- `tap-backend/src/config/window.rs`：`WindowMode` 的 `#[default]` 由 Windowed 移到 Maximized（无配置时窗口最大化启动）
- `tap-backend/src/config/defaults.rs`：`default_opacity()` 1.0 → 0.8（**后经用户复核，有意改回 1.0**：窗口默认不透明，透明度留给用户按需配置；该修正暂在工作区未提交）
- 其余项核对：use-drawable-chars 默认 true ✓、style 默认 Default ✓、features/symbol-map/additional-dirs 默认与用户配置等价 ✓、margin/line-height 未在用户配置中（走默认）✓、背景图默认已由 20261118-1941 任务完成 ✓
- 验证：`cargo check -p tapterm`、`cargo check -p sugarloaf --features wgpu` 通过；`cargo test -p tap-backend config::`（88 passed）、`cargo test -p sugarloaf`（138 passed）
- 效果：新安装无配置文件时 = Fira Code SemiBold 18 号 + 最大化 + 窗口不透明（opacity 1.0，用户复核后改回）+ 默认背景图；用户可在 `~/.config/tap/config.toml` 中逐项覆盖
