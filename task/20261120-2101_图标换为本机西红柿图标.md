# 图标换为本机西红柿图标

## 背景

用户要求把项目当前在用的图标换成本机的西红柿图标（tomto icon）。本机图标主题为 Flat-Remix-Blue-Dark，其 `apps/scalable/tomato.svg`（红番茄 + 绿叶矢量，viewBox 384×384）即目标图标。

项目图标在用链路（Linux 边界内两处）：

1. 桌面图标：`misc/logo.svg` 为源，经 `.goreleaser.yaml` / `pkgTap.nix` / `frontends/tapterm/Cargo.toml`（cargo-deb assets）安装为 `usr/share/icons/hicolor/scalable/apps/tap.svg`，`misc/tap.desktop` 以 `Icon=tap` 引用。
2. 窗口图标（X11 标题栏/任务栏）：`frontends/tapterm/src/router/window.rs` 的 `LOGO_ICON = include_bytes!(.../tap-logo.ico)`（原 410598 字节）。

`misc/logo-2024.svg` 为历史版本无构建引用，不动；`build.rs` 的 ico 引用为 windows-only 宿主门控，Linux 不编译，保持文件名 `tap-logo.ico` 不变即无影响。

## 实施

- `misc/logo.svg`：直接以 `/usr/share/icons/Flat-Remix-Blue-Dark/apps/scalable/tomato.svg` 覆盖（原 rio logo，含 base64 位图 23KB → 纯矢量 3.3KB）；所有打包脚本引用的文件名不变，零改动。
- `tap-logo.ico`：ffmpeg（librsvg）将 tomato.svg 渲染 16/32/48/64/128/256 六档 PNG，python 手工合成 PNG-in-ICO（ICONDIR + 6×ICONDIRENTRY + PNG 载荷，Vista+ 格式，image crate 支持）覆盖原文件，410598 → 33878 字节。
- `window.rs:7`：`LOGO_ICON` 常量大小同步 410598 → 33878。
- 重建 `target/release/tap` 并安装至 `/usr/local/bin/tap`（窗口图标内嵌二进制，必须重建才生效）。

## 验证

- `cargo check -p tapterm` 通过；release 重建成功。
- 待用户手测：启动 tap 观察任务栏/标题栏为西红柿图标；安装 deb/nix 后桌面启动器图标同步更换。
