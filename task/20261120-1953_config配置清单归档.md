# config 配置清单归档

## 背景

用户要求整理一份完备的配置清单归档到 docs/，描述每个配置项的作用、写法、默认值、可选值。此前快捷键已有独立清单，配置侧只有源码散落在 tap-backend/src/config/ 等 4 处，无统一文档。

## 设计

- 事实来源以源码为准，逐文件通读后落档：
  - `tap-backend/src/config/`：mod.rs（Config 主体、Scroll、Developer、Shell、CursorConfig、加载/合并逻辑）+ 15 个子文件（window/navigation/renderer/keyboard/title/bell/command_finished/effects/hints/input_bar/layout/bindings/platform/theme/defaults）
  - `tap-vt/src/config/colors/`：Colors 全部键与默认色值（mod.rs + defaults.rs）
  - `sugarloaf/src/font/fonts.rs`：SugarloafFonts 全部键
  - `frontends/tapterm/src/cli.rs`：CLI 参数；`bindings/mod.rs`：action 词表与 mode 解析（appcursor/appkeypad/alt/vi 及 ~ 取反）
  - `sugarloaf/src/sprite/mod.rs`：确认 use-drawable-chars 语义（内置 sprite 程序化绘制制表符/块元素/盲文/Powerline）
- 文档结构：位置与加载机制 → 顶层项 → 各 [section]（逐键：作用/写法/默认值/可选值）→ [platform] 合并语义 → CLI → 环境变量 → 最小示例 → 本 fork 与上游 rio 默认值差异备忘。
- 关键易错点显式写入：主题文件颜色优先于内联 [colors]；option-as-alt 取值集；scroll multiplier/divider 钳制区间；max-tab-width 钳制 [80,280]；background-image 本 fork 默认启用；disable-mouse 本 fork 收窄语义（保留选中/中键粘贴）。
