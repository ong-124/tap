# 任务：Warp 式底部统一输入框

## 背景与目标

像 Warp 终端一样，在终端窗口底部提供一个统一的输入框：所有键盘输入先进入底部输入栏，支持行内编辑与历史记录，回车后将整行命令发送到 PTY，输出区（上方终端面板）只读展示。

## 需求细节

- 底部固定输入栏，光标常驻输入栏
- 行内编辑：左右移动、Home/End、退格、删除、Ctrl+W 等
- 历史记录：上/下翻阅已执行命令
- 回车提交：整行（含换行）写入 PTY；清空输入栏
- 可配置启用/禁用：关闭后回到传统"直接输入到终端"模式

## 设计调研（20261118 架构调研结论）

- 参考现有覆盖层 UI：`frontends/rioterm/src/renderer/command_palette.rs`（命令面板）、`island.rs`、`search.rs`、`assistant.rs`
- 渲染 API：`sugarloaf/src/sugarloaf.rs`（`rect` L566、render 系列 L909-1133）；富文本布局 `sugarloaf/src/layout/mod.rs`（`RichTextConfig` L146）、`sugarloaf/src/span.rs`、UI 文本 `sugarloaf/src/text.rs`
- 键盘事件链路：`frontends/rioterm/src/application.rs` L2215 `WindowEvent::KeyboardInput` → `frontends/rioterm/src/router/mod.rs` `has_key_wait` L268（overlay 优先接管输入）→ `frontends/rioterm/src/screen/mod.rs::process_key_event` L802
- 输出到 PTY：`frontends/rioterm/src/messenger.rs::send_write`（corcovado channel）
- 终端区滚动/布局：输入栏占位需要与终端内容区布局协调（避免遮挡最后一行）

## 关键子任务

1. 输入栏 UI 与渲染层（底部固定栏，sugarloaf 富文本）
2. 输入缓冲与编辑（光标移动、历史记录）
3. 提交发送整行命令到 PTY
4. 可配置启用/禁用（保留传统直接输入模式）
