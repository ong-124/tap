# Tap 快捷键清单（默认值）

> 归档自 `frontends/rioterm/src/bindings/mod.rs` 默认绑定表（2026-11-19 更新：去除 `[` / `]` 切换，标签改 Ctrl+Tab / `<leader>`+数字，分屏改 `<leader>`+h/j/k/l，默认屏蔽鼠标）。
> `<leader>` = 老板键（前缀键），默认 `ctrl+shift`，可在配置中整体更换，见下文「配置方式」。

---

## 老板键 `<leader>` 与配置方式

### 一键更换老板键

所有带前缀的内置快捷键共用一个前缀，在 `~/.config/tap/config.toml` 中一处配置即可整体切换：

```toml
[bindings]
prefix = "ctrl+shift"    # 默认值；可改为 "alt"、"super | ctrl"、"shift+alt" 等
```

- 分隔符支持 `+` 或 `|`，大小写不敏感
- 修饰键词表：`control` / `ctrl`、`shift`、`alt` / `option`、`super` / `cmd` / `command`、`none`
- 改完保存即热重载生效，无需重启
- 不配置则保持 `ctrl+shift`，与旧版习惯完全一致

**受影响的快捷键**：下文所有以 `<leader>` 标注的按键（复制/粘贴/搜索/标签/分屏/命令面板等）。
**不受影响**：单独使用 Ctrl 的键（如 Ctrl+Tab、Ctrl+字号）、Shift 单键、Alt 键、VI 模式内按键等。

### 自定义 / 覆盖单个绑定

`[bindings] keys` 中可新增或覆盖绑定（同名按键组合自动替换内置项），`with` 字段同样支持 `prefix` 写法，跟随老板键配置：

```toml
[bindings]
prefix = "alt"

[[bindings.keys]]
key = "e"
with = "prefix"          # 解析为老板键（此处即 alt）
action = "splitright"

[[bindings.keys]]
key = "w"
with = "prefix | shift"  # 老板键可再叠加其他修饰键
action = "quit"
```

常用 action 名称（不区分大小写）：`copy`、`paste`、`quit`、`receivechar`、`selectall`、`clearhistory`、`resetfontsize` / `increasefontsize` / `decreasefontsize`、`createwindow`、`togglequake`、`createtab`、`closetab`、`closesplitortab`、`closeunfocusedtabs`、`selectprevtab` / `selectnexttab` / `selectlasttab`、`selecttab(n)`、`movecurrenttabtoprev` / `movecurrenttabtonext`、`splitright` / `splitdown`、`selectsplitleft` / `selectsplitdown` / `selectsplitup` / `selectsplitright`、`selectnextsplit` / `selectprevsplit`、`selectnextsplitortab` / `selectprevsplitortab`、`scrollpageup` / `scrollpagedown`、`scrolltotop` / `scrolltobottom`、`searchforward` / `searchbackward`、`openconfigeditor`、`configeditor` 等；完整清单见 `frontends/rioterm/src/bindings/mod.rs` 的 `From<String> for Action`。

## Linux 默认快捷键（当前平台）

### 剪贴板

| 按键 | 动作 |
| --- | --- |
| `<leader>` + C | 复制（VI 模式下为清除选区） |
| `<leader>` + V | 粘贴 |
| Shift + Insert | 粘贴选区（PRIMARY 选区） |
| 鼠标中键 | 粘贴选区（PRIMARY 选区；默认屏蔽鼠标，需 `disable-mouse = false`） |
| 键盘 Copy / Paste 键 | 复制 / 粘贴（若键盘有此类键） |

### 字体

| 按键 | 动作 |
| --- | --- |
| Ctrl + 0 | 重置字号 |
| Ctrl + = / Ctrl + + | 增大字号 |
| Ctrl + - | 减小字号 |

### 窗口 / 标签页（navigation 默认 Tab 模式）

| 按键 | 动作 |
| --- | --- |
| `<leader>` + N | 新建窗口 |
| `<leader>` + T | 新建标签 |
| `<leader>` + W | 关闭当前分屏或标签 |
| Ctrl + Tab | 下一个标签 |
| `<leader>` + Tab（即 Ctrl+Shift+Tab） | 上一个标签 |
| `<leader>` + 1 … 8 | 切到第 1 … 8 个标签 |
| `<leader>` + 9 | 切到最后一个标签 |
| `<leader>` + , | 打开配置编辑器 |
| `<leader>` + P | 打开命令面板 |

### 分屏（use-split 默认开启）

| 按键 | 动作 |
| --- | --- |
| `<leader>` + R | 向右分屏 |
| `<leader>` + D | 向下分屏 |
| `<leader>` + H | 焦点移到左边的分屏（vi 风格，当前标签内） |
| `<leader>` + J | 焦点移到下边的分屏 |
| `<leader>` + K | 焦点移到上边的分屏 |
| `<leader>` + L | 焦点移到右边的分屏 |
| `<leader>` + Alt + ↑/↓/←/→ | 移动分屏分隔线 |

> 方向切换只在当前标签内移动；该方向没有分屏时不动。循环切换（`selectnextsplit` / `selectprevsplit`）不再绑定默认键，需要时可在 `[[bindings.keys]]` 自行绑定。

### 搜索

| 按键 | 动作 |
| --- | --- |
| `<leader>` + F | 向前搜索 |
| `<leader>` + B | 向后搜索 |

搜索栏内：

| 按键 | 动作 |
| --- | --- |
| Ctrl + C | 取消搜索 |
| Ctrl + U | 清空搜索词 |
| Ctrl + W | 删除一个词 |
| Ctrl + P / ↑ | 上一条历史搜索 |
| Ctrl + N / ↓ | 下一条历史搜索 |
| Enter | 确认 / 跳到下一匹配 |
| Shift + Enter | 跳到上一匹配 |
| Esc | 取消搜索 |

### 底部输入栏（enable-input-bar 默认开启）

命令行编辑（shell 回到提示符时输入栏激活；命令运行中按键直通焦点分屏）。历史为 tap 自建持久库（`~/.config/tap/input-history`，跨会话），非 shell 历史文件：

| 按键 | 动作 |
| --- | --- |
| 可打印字符 | 输入到行内（含中文 IME） |
| Enter | 提交整行到 PTY（含 \r），并写入 tap 自建历史库 |
| Backspace / Delete | 向前 / 向后删除一个字符 |
| Ctrl / Alt + Backspace、Ctrl + W | 删除光标前一个词 |
| Ctrl + U | 删除到行首 |
| ← / → | 光标左 / 右移动（光标在行尾且有虚化建议时，→ 接受建议） |
| Home / End | 跳到行首 / 行尾（有虚化建议时，End 接受建议） |
| ↑ / ↓ | 上一条 / 下一条历史命令（持久库，跨会话） |
| → / End（有建议时） | 接受虚化建议（zsh-autosuggestions 式暗色续写，编辑即消失） |
| Tab | 补全：首词 = PATH 可执行 + 常用内建；其余词 = 焦点分屏 cwd 下路径（`~` 展开、目录补 `/`）；多候选补公共前缀并显示候选行，连续 Tab 循环切换 |
| Shift + Tab（BackTab） | 直通焦点分屏的 PTY |
| Ctrl + C | 直通 shell 中断，同时清空输入栏 |
| Ctrl + D / L 等其他 Ctrl 组合 | 直通焦点分屏的 PTY |
| Escape | 直通焦点分屏的 PTY |

补充：`[input-bar] record-history = false` 停止记录历史；`suggestions = false` 关闭虚化建议（均热重载生效）。用户自定义的裸 Tab 绑定优先于输入栏补全。

| 按键 | 动作 |
| --- | --- |
| Alt + Shift + Space | 进入/退出 VI 模式 |
| Esc | 清除选区；有选区时再按退出 VI 模式（两段式） |
| v | 字符选择 |
| V（Shift+v） | 行选择 |
| Ctrl + v | 块选择 |
| Alt + v | 语义选择 |
| y | 复制选区（同时写入剪贴板与 PRIMARY，配合中键粘贴） |
| h / j / k / l 或方向键 | 移动光标 |
| w / b / e | 词右 / 词左 / 词尾 |
| W / B / E（Shift） | 空白分词移动 |
| 0 | 行首 |
| $（Shift+4） | 行尾 |
| ^（Shift+6） | 行首非空白 |
| g | 跳到顶部 |
| G（Shift+g） | 跳到底部 |
| H / M / L（Shift） | 屏幕顶 / 中 / 底 |
| %（Shift+5） | 括号匹配 |
| {（Shift+[） | 上一段落 |
| }（Shift+]） | 下一段落 |
| Ctrl + b / f | 上 / 下翻页 |
| Ctrl + u / d | 上 / 下翻半页 |
| Ctrl + y / e | 上 / 下滚一行 |
| / | 搜索（VI 模式内） |
| n / N | 下一个 / 上一个匹配 |
| z | 光标居中 |
| i | 退出 VI 模式（回到输入） |

### 链接提示（Hints）与鼠标

| 操作 | 动作 |
| --- | --- |
| Ctrl + Shift + O | 打开链接/路径提示，按标签字母打开（默认提示词） |
| Alt + 鼠标悬停 | 高亮链接/路径（macOS 为 Super 悬停） |
| 单击链接 | 打开（OSC 8 超链接） |

> 注意 1：`Ctrl + Shift + O` 来自 `[hints]` 默认规则，是独立的 `["Control","Shift"]` 写死的绑定，**不跟随** `[bindings] prefix` 变化；如需更换请在 `[[hints.rules.binding]]` 中单独配置。
> 注意 2：默认 `disable-mouse = true`（见下节），悬停/单击行需要关闭屏蔽才可用；纯键盘场景用 Ctrl + Shift + O 提示打开链接。

### 鼠标（默认屏蔽）

tap 重度使用键盘，鼠标默认整体屏蔽（点击、拖拽、滚轮、悬停、中键粘贴全部无效）：

```toml
disable-mouse = true    # 默认值；改 false 恢复鼠标交互
```

- 事件在应用层直接丢弃，不会转发给终端内程序（vim/tmux 等收不到鼠标事件）
- 需要鼠标时改 `false` 保存即热重载生效
- 纯键盘替代：选择/复制用 VI 模式（Alt+Shift+Space），滚动用 Shift+PageUp/PageDown、Shift+Home/End，链接用 Ctrl+Shift+O 提示

### 其他

| 按键 | 动作 |
| --- | --- |
| Ctrl + L | 清除屏幕通知；无通知时向 shell 发送清屏（\x0c） |
| Shift + Home / End | 滚到顶部 / 底部（主屏） |
| Shift + PageUp / PageDown | 上 / 下翻页（主屏） |
| Super + 方向键 | 屏蔽（不触发终端动作） |

> 方向键、F1-F4、Insert/Delete/PageUp/PageDown、Backspace 等在对应终端模式（AppCursor / Kitty 协议等）下按标准转义序列透传给 shell，不属于可配置快捷键，此处不逐一列出。

## macOS 差异

macOS 上以 `Super（Cmd）` 为主，老板键仅用于少量键位：

| 按键 | 动作 |
| --- | --- |
| Cmd + C / V / A | 复制 / 粘贴 / 全选（VI 下 Cmd+C 清除选区） |
| Cmd + Q / N / W | 退出 / 新窗口 / 关闭分屏或标签 |
| Cmd + T / 数字 1-9 | 新标签 / 切到第 n 个标签（9 为最后一个） |
| Ctrl + Tab / `<leader>` + Tab | 下一个 / 上一个标签 |
| Cmd + F / B | 向前 / 向后搜索 |
| Cmd + +/-/0 | 字号增 / 减 / 重置 |
| Cmd + K | 清除历史（配合通知） |
| Cmd + , | 配置编辑器 |
| Cmd + P | 命令面板 |
| Cmd + H / M | 隐藏窗口 / 最小化 |
| Cmd + Alt + H | 隐藏其他应用 |
| Ctrl + Cmd + F | 全屏切换 |
| Cmd + D / Shift+D | 右分屏 / 下分屏 |
| `<leader>` + H/J/K/L | 分屏焦点向左 / 下 / 上 / 右移动（vi 风格） |
| Ctrl + Cmd + 方向键 | 移动分隔线 |
| Alt + ←/→ | 发送 \x1bb / \x1bf（可配置关闭） |

## Windows 差异

与 Linux 基本一致（标签 Ctrl+Tab / `<leader>`+Tab / `<leader>`+1-9，分屏 `<leader>`+R/D/H/J/K/L），额外：

| 按键 | 动作 |
| --- | --- |
| `<leader>` + Space | 进入/退出 VI 模式（Linux 为 Alt + Shift + Space） |
| Alt + Enter | 全屏切换 |
| Ctrl + Backspace | 发送 \x17（PowerShell 删词） |

## 备注

- quake（老板窗）全局热键默认未注册；需要时在 `[[bindings.keys]]` 中加 `action = "togglequake"` 的绑定（如 `key = "q", with = "prefix"`）。
- `navigation.mode = "Plain"` 时标签类快捷键（T/W/Tab/数字键）整体停用；`use-split = false` 时分屏类快捷键停用。
- `[` / `]` 的标签、分屏循环切换绑定已移除（与分屏切换重复）；需要循环切换时用 action `selectnextsplit` / `selectprevsplit` 自行绑定。
- 本清单随内置绑定表维护，若改动 `bindings/mod.rs` 默认表请同步更新本文档。
