# Tap 配置清单（config.toml）

> 归档自源码（2026-11-20）：`tap-backend/src/config/`（主结构与全部子节）、`tap-vt/src/config/colors/`（颜色与默认值）、`sugarloaf/src/font/fonts.rs`（字体）、`frontends/tapterm/src/cli.rs`（CLI 参数）、`frontends/tapterm/src/bindings/mod.rs`（action 词表）。
> 本文覆盖全部可配置项的：作用、写法、默认值、可选值。键名一律 kebab-case；未配置的键取默认值；解析失败整文件回退默认并告警。

---

## 1. 配置文件：位置、生成、加载

| 事项 | 说明 |
|---|---|
| 路径（Linux） | `$TAP_CONFIG_HOME/config.toml`，未设则 `$XDG_CONFIG_HOME/tap/config.toml`，再未设则 `~/.config/tap/config.toml` |
| 路径（macOS） | `$TAP_CONFIG_HOME/config.toml`，未设则 `~/.config/tap/config.toml` |
| 路径（Windows） | `$TAP_CONFIG_HOME/config.toml`，未设则 `%LOCALAPPDATA%\tap\config.toml` |
| 生成 | `tap --write-config [PATH]`；默认内容仅一行注释，几乎全部行为依赖内置默认值 |
| 主题目录 | `{配置目录}/themes/{主题名}.toml`，文件内只写 `[colors]` 节 |
| 热重载 | 配置目录有 watcher，保存即生效（无需重启）；CLI 启动参数覆盖在重载后仍保留 |
| 优先级 | 平台覆盖块（§20）> config.toml > 内置默认；CLI 参数（§21）最后叠加 |

## 2. 顶层配置项

### 2.1 Shell 与进程

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `shell` | 内联表 | `{ args = ["--login"] }`（Windows: powershell） | 启动的 shell。`program` 不写或写 `""` = 用户默认 shell（login shell）；`args` 传参。写法：`shell = { program = "/bin/fish", args = ["--hello"] }` |
| `editor` | 内联表 | `vi`（Windows: notepad） | `openconfigeditor` 动作打开配置文件所用编辑器。写法：`editor = { program = "nvim", args = [] }` |
| `use-fork` | bool | Linux/Windows `true`，macOS `false` | 以 fork 方式启动 shell |
| `shell-integration` | bool | `true` | 向 spawn 的 zsh / fish 自动注入 shell 集成（OSC 7 工作目录、OSC 133 命令标记等，零用户配置）；bash / cmd 不注入 |
| `working-dir` | string | 无 | 初始工作目录（绝对路径） |
| `env-vars` | string[] | `[]` | 注入 shell 的环境变量，写法 `env-vars = ["A=5", "B=8"]` |
| `hold` | bool | `false` | 命令退出后保留 pane 直到按任意键（等价 CLI `--hold`） |

### 2.2 外观与行为

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `theme` | string | `""` | 主题名，加载 `themes/{theme}.toml`；**主题文件中的颜色覆盖 config.toml 内联 `[colors]`** |
| `adaptive-theme` | 内联表 | 无 | 亮暗两套主题跟随系统切换：`adaptive-theme = { light = "主题A", dark = "主题B" }`（两文件都必须存在，否则报错） |
| `force-theme` | string | 无 | 强制外观：`"dark"` / `"light"` |
| `line-height` | float | `1.0` | 行高倍数 |
| `margin` | 数组 | `[2.0]` | 终端内容四周留白（逻辑像素），CSS 风格 1 / 2 / 4 值：`[10]` 四边、`[10, 5]` 上下/左右、`[10, 5, 15, 20]` 上右下左 |
| `confirm-before-quit` | bool | `true` | 退出前确认对话框 |
| `copy-on-select` | bool | `false` | 选中即复制到剪贴板（关闭时选中只写 PRIMARY，中键粘贴） |
| `hide-mouse-cursor-when-typing` | bool | `false` | 打字时隐藏鼠标指针；别名 `hide-cursor-when-typing` |
| `disable-mouse` | bool | `true` | 键盘优先，屏蔽鼠标 UI 交互（本 fork 语义：点击不改焦点、屏蔽滚轮/悬停/分隔线/Hint/PTY 上报；保留拖拽/双击/三击选中与中键粘贴） |
| `ignore-selection-foreground-color` | bool | `false` | 选区忽略程序设置的前景色 |
| `draw-bold-text-with-light-colors` | bool | `false` | 粗体字改用亮色变体绘制 |
| `grapheme-clustering` | bool | `true` | 以 Unicode 字素簇为单元格布局单位（预设 DEC 私有模式 2027；程序运行时 DECSET/DECRST 优先于配置） |
| `enable-scroll-bar` | bool | `true` | 显示滚动条 |
| `scrollback-history-limit` | int | `10000` | 回滚历史行数上限；`0` 禁用回滚 |
| `option-as-alt` | string | `"none"` | Option 键当 Alt 用：`"none"` / `"both"` / `"left"` / `"right"`（大小写不敏感） |

|---|---|---|---|

| `height` | int | `490` | 窗口高 |

| `colorspace` | string | `"srgb"` | 颜色解释域：`"srgb"` / `"display-p3"` / `"rec2020"`（决定 hex/ANSI 颜色值按哪套基色解释） |
| `columns` | int | 无 | 以字符列数定初始尺寸（优先于 width/height 的像素换算） |
| `rows` | int | 无 | 以字符行数定初始尺寸 |
| `background-image` | 表 | **本 fork 默认启用**：项目内 `background/t013c2f41e0a5020acc.jpg`，`opacity = 1.0` | 背景图：`[window.background-image] path = "..."`、`opacity`（仅图像与背景色混合比例，不影响字符对比度）；不想要背景图可把 `path` 指向不存在文件（加载失败仅为可关闭的警告） |
| `initial-title` | string | 无 | 初始标题（序列化时跳过，运行期状态） |
| `quake-width-percentage` | float | `1.0` | Quake 下拉窗宽占屏幕比例 |
| `quake-height-percentage` | float | `0.4` | Quake 下拉窗高占屏幕比例 |
| `macos-use-unified-titlebar` | bool | `false` | macOS 一体化标题栏 |
| `macos-use-shadow` | bool | `true` | macOS 窗口阴影 |
| `macos-traffic-light-position-x/y` | float | 无 | macOS 红绿灯按钮位置偏移 |
| `windows-use-undecorated-shadow` | bool | 无 | Windows 无边框阴影 |
| `windows-use-no-redirection-bitmap` | bool | 无 | Windows 关闭重定向位图 |
| `windows-corner-preference` | string | 无 | `"default"` / `"donotround"` / `"round"` / `"roundsmall"` |

```toml
[window]
mode = "Windowed"
width = 1200
height = 800
opacity = 0.95
blur = true

[window.background-image]
path = "/home/ong/Pictures/wall.png"
opacity = 0.35
```

## 5. `[navigation]` 标签条与导航

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `mode` | string | `"Tab"` | `"Tab"`（GPU 渲染标签条）/ `"Plain"`（无标签条）；macOS 另有 `"NativeTab"` |
| `clickable` | bool | `false` | 标签条可鼠标点击切换 |
| `current-working-directory` | bool | `true` | 新标签继承当前工作目录；别名 `cwd` |
| `use-terminal-title` | bool | `false` | 标签用终端标题（OSC 0/2） |
| `hide-if-single` | bool | macOS `true`，Linux/Windows `false` | 仅一个标签时隐藏标签条（Linux 上单标签退化为居中标题） |
| `use-split` | bool | `true` | 启用分屏功能 |
| `open-config-with-split` | bool | `true` | 打开配置时用分屏 |

```toml
    { program = 'ssh',   color = '#F1F1F1' },
    { path = '/home',    color = '#ffffff' },
    { program = 'nvim', path = '/usr', color = '#00b952' },  # 两条件都满足
]
```

## 6. `[renderer]` 渲染

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `backend` | string | Linux `"Vulkan"`，macOS `"Metal"`，其余 `"Webgpu"` | `"Vulkan"`（Linux 原生，其余平台走 wgpu）/ `"Webgpu"`（wgpu 自动选 Metal/Vulkan/DX12/GL，需 wgpu feature）/ `"Metal"`（仅 macOS） |

## 7. `[fonts]` 字体

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `size` | float | `18.0` | 字号 |
| `family` | string | `"Fira Code SemiBold"`（本 fork 固化默认） | 顶层 family 一次性覆盖下面四个 slot；缺失时告警并回落内置 Cascadia Code |
| `hinting` | bool | `true` | 字形微调 |
| `features` | string[] | 无 | OpenType 特性，如 `["ss01", "liga"]` |
| `regular` / `bold` / `italic` / `bold-italic` | 表 | 各 slot 按名称自动匹配 | 每槽字段：`family`（字体族）、`style`、`weight` |
| `use-drawable-chars` | bool | `true` | 制表符/块元素/盲文/Powerline 等由内置 sprite 程序化绘制（与字体无关、按 cell 尺寸光栅化，无缝且清晰）；关闭则交给当前字体渲染 |
| `symbol-map` | 数组 | 无 | 码点区间 → 指定字体：`[{ start = "2297", end = "2299", font-family = "PowerlineSymbols" }]`（start/end 为十六进制码点） |
| `disable-warnings-not-found` | bool | `false` | 关闭字体缺失告警 |
| `additional-dirs` | string[] | 无 | 额外字体搜索目录 |

`style` 三种写法：`"default"`（按槽位常规/粗/斜自动选，默认）、`false`（禁用该槽，回落 regular 字形）、样式名字符串（如 `"Light"` / `"Medium"` / `"Heavy"`，由 CoreText / fontconfig 解析）。
`weight`：100–900 的 CSS 风格字重，可选，控制变字重字体轴。

```toml
[fonts]
size = 16.0
family = "JetBrains Mono"

[fonts.bold]
family = "JetBrains Mono"
style = "ExtraBold"

fonts.symbol-map = [
    { start = "E0C0", end = "E0C7", font-family = "Cascadia Code NF" },
]
```

## 13. `[hints]` 提示标签（jump label）

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `alphabet` | string | `"jfkdls;ahgurieowpq"` | 标签字符表（按键盘可达性排序） |
| `rules` | 数组 | 内置 1 条：URL/路径正则 + OSC 8 超链接 + `Open` 动作 + `Ctrl+Shift+O` 触发 + 鼠标高亮（Linux `Alt`、macOS `Super`） | 规则列表，见下 |

单条规则字段（`[[hints.rules]]`）：

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `regex` | string | 无（默认规则用内置 URL/路径正则，覆盖 http/ftp/file/ssh 等协议 URL、`/abs`、`./rel`、`../rel`、`~/x`、`$VAR/x`、`word/name.ext` 路径） | oniguruma 正则（支持 lookbehind） |
| `hyperlinks` | bool | `false` | 是否包含 OSC 8 超链接 |
| `post-processing` | bool | `true` | 裁掉匹配尾部的标点/未闭合括号（OSC 8 不裁） |
| `persist` | bool | `false` | 选中后提示标签不消失 |
| `action` | string | 无 | 内建动作：`"Copy"` / `"Paste"` / `"Select"` / `"MoveViModeCursor"` / `"Open"`（交系统默认打开器；匹配文本来自终端输出，属不可信输入，默认动作不走 shell） |
| `command` | string/表 | 无 | 自定义命令，与 `action` 二选一：`command = "open"` 或 `command = { program = "open", args = ["-R"] }` |
| `mouse` | 表 | `{ enabled = true, mods = ["Alt"] }`（macOS `["Super"]`） | 鼠标高亮：`enabled`、`mods`（修饰键数组） |
| `binding` | 表 | 无 | 键盘触发：`{ key = "O", mods = ["Control", "Shift"], mode = [] }` |

```toml
[[hints.rules]]
regex = "test.*pattern"
hyperlinks = false

[hints.rules.action]
action = "Copy"

[hints.rules.binding]
key = "T"
mods = ["Control"]
```

| `trail-cursor-opacity` | float | `1.0` | 拖尾不透明度 0.0–1.0 |

| `trail-cursor-start-threshold` | int | `2` | 光标跳变 ≤ 此格数不触发拖尾；`0` = 每次移动都动画 |

```toml
[effects]
trail-cursor = true
trail-cursor-color = "#F07178"
trail-cursor-opacity = 0.4
trail-cursor-decay = [50, 250]
trail-cursor-start-threshold = 0
```

## 16. `[input-bar]` 底部统一输入栏

总开关是顶层 `enable-input-bar`（默认 `true`）。本节控制几何与行为：

| 键 | 类型 | 默认值 | 说明 / 可选值 |
|---|---|---|---|
| `width` | number/string | `"100%"` | 栏宽：像素裸数（`900`）或百分比字符串（`"60%"`，0–100 钳制），水平居中 |
| `height` | number/string | 无 | 栏高：px 或百分比；不设 = 按六行终端行高（文字为终端字体两倍大小）预留 |
| `record-history` | bool | `true` | 提交行记入持久输入历史库（SQLite，带 ts/cwd/exit 元数据；密文行不入库） |
| `suggestions` | bool | `true` | 虚化补全（zsh-autosuggestions 风格：光标尾部暗色续写，→ / End 整体接受，Ctrl+→ 逐词接受） |
| `dynamic-completion` | bool | `true` | 动态补全：Cobra `__complete` 协议（kubectl 等）+ ssh 主机/远程路径补全；关闭仅回退静态命令/路径补全 |
| `command-aliases` | 表 | 无 | 别名 → 真实命令，仅供动态补全路由：`{ k = "kubectl" }` 使 `k get pod<Tab>` 查询 kubectl |

```toml
[input-bar]
width = "60%"
height = 200
record-history = true
suggestions = true
dynamic-completion = true

[input-bar.command-aliases]
k = "kubectl"
h = "helm"
```

## 18. `[bindings]` 快捷键

> 完整默认绑定表见 [20261118-2150_快捷键清单.md](20261118-2150_快捷键清单.md)。此处只列配置写法。

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `prefix` | string | `"ctrl+shift"` | 老板键（前缀键），所有带前缀的内置快捷键共用；分隔符 `+` 或 `\|`，修饰词：`control`/`ctrl`、`shift`、`alt`/`option`、`super`/`cmd`/`command`、`none` |
| `keys` | 数组 | `[]` | 自定义绑定列表；与内置同键组合自动覆盖 |

单条绑定字段：

| 键 | 说明 |
|---|---|
| `key` | 按键名：单字符（`"w"`）、功能键（`"Home"`、`"F1"`）、修饰键本身（`"Control"`） |
| `with` | 修饰键组合：`"super"`、`"super \| shift"`、或 `"prefix"` / `"prefix \| alt"` 跟随老板键 |
| `action` | 动作名（见下表；不区分大小写） |
| `esc` | 直接向 PTY 写转义序列，与 action 互斥使用；TOML 双引号支持 `\u001b` 写法 |
| `mode` | 绑定生效条件，`\|` 分隔多值：`appcursor` / `~appcursor`、`appkeypad` / `~appkeypad`、`alt` / `~alt`（alt screen）、`vi` / `~vi`；`~` 前缀表示"该模式未开启时" |

action 全量词表（`From<String> for Action`，不匹配即 `none`）：

- **剪贴板/通用**：`copy`、`paste`、`selectall`、`quit`、`none`、`receivechar`、`clearhistory`、`createwindow`、`togglequake`、`togglefullscreen`、`toggleappearancetheme`、`openconfigeditor`、`opencommandpalette`
- **字号**：`increasefontsize`、`decreasefontsize`、`resetfontsize`
- **标签**：`createtab`、`closetab`、`closesplitortab`、`closeunfocusedtabs`、`selectprevtab`、`selectnexttab`、`selectlasttab`、`selecttab(n)`、`movecurrenttabtoprev`、`movecurrenttabtonext`
- **分屏**：`splitright`、`splitdown`、`selectnextsplit`、`selectprevsplit`、`selectsplitleft`、`selectsplitdown`、`selectsplitup`、`selectsplitright`、`selectnextsplitortab`、`selectprevsplitortab`、`movedividerup`、`movedividerdown`、`movedividerleft`、`movedividerright`、`togglebroadcast`
- **滚动**：`scrollpageup`、`scrollpagedown`、`scrollhalfpageup`、`scrollhalfpagedown`、`scrolltotop`、`scrolltobottom`、`scrolltoprevprompt`、`scrolltonextprompt`、`scroll(n)`
- **搜索**：`searchforward`、`searchbackward`、`searchconfirm`、`searchcancel`、`searchclear`、`searchfocusnext`、`searchfocusprevious`、`searchdeleteword`、`searchhistorynext`、`searchhistoryprevious`
- **VI**：`togglevimode`、`clearselectionorexitvi`
- **带参数**：`selecttab(n)`（切第 n 个标签）、`run(命令 参数…)`（执行程序）、`scroll(n)`（滚 n 行，负数向上）

```toml
[bindings]
prefix = "ctrl+shift"

[[bindings.keys]]
key = "e"
with = "prefix"
action = "splitright"

[[bindings.keys]]
key = "Home"
esc = "\u001b[5~"        # 向终端发转义序列

[[bindings.keys]]
key = "k"
with = "control"
action = "run(htop -u ong)"
```

## 19. `[platform]` 平台覆盖

三个子块 `[platform.linux]` / `[platform.windows]` / `[platform.macos]`，仅当前平台的块生效，其余忽略。合并语义：

- `shell` —— **整表替换**（program + args）
- `theme` —— 替换
- `env-vars` —— **追加**到全局 env-vars 之后
- `window` / `navigation` / `renderer` —— **字段级合并**，只覆盖写出的字段

可覆盖字段（全部可选）：`shell`、`theme`、`env-vars`、`window`（width/height/mode/opacity/blur/background-image/decorations/colorspace/columns/rows 及全部 macos-*/windows-* 字段）、`navigation`（mode/color-automation/clickable/current-working-directory/use-terminal-title/hide-if-single/use-split/open-config-with-split/max-tab-width）、`renderer`（backend/disable-unfocused-render/disable-occluded-render/filters/strategy）。

```toml
[platform.linux]
env-vars = ["LIBGL_ALWAYS_SOFTWARE=0"]

[platform.linux.renderer]
backend = "Vulkan"
```

## 20. CLI 参数（叠加于配置之上，重载后保留）

| 参数 | 说明 |
|---|---|
| `-e, --command <CMD>...` | 直接执行命令（须为最后参数）；同时关闭 use-fork |

| `-V, --version` / `--help` | 版本 / 帮助 |
